Moving Towards a More Aggressive Release Cycle

August 20, 2023

Moving Towards a More Aggressive Release Cycle

The Lunar Linux team is excited to announce that we are implementing a more aggressive release cycle to better serve our users and keep pace with the rapidly evolving Linux ecosystem.

What This Means For Users

Starting immediately, we'll be working to provide more frequent releases with a focus on:

  • Regular ISO updates: New installation media will be released more frequently to incorporate the latest kernel versions and critical package updates.
  • Improved hardware support: Faster release cycles mean better support for new hardware components as they become available.
  • More timely security updates: Critical security patches will be incorporated and distributed more quickly.
  • Streamlined testing process: We're improving our testing infrastructure to maintain quality while increasing development speed.

Why We're Making This Change

As hardware advances and security concerns become increasingly important, the traditional extended release cycle is no longer optimal for a modern distribution. Many of our users have requested more frequent updates, particularly for hardware enablement and security patches.

This change also aligns with our goal of making Lunar Linux both powerful and accessible. By providing more frequent releases, we can ensure that new users have a smooth installation experience with modern hardware, while existing users benefit from improved stability and security.

Looking Forward

Our development team is already hard at work implementing these changes. You can expect to see the first results of this new approach in the coming months.

We're committed to maintaining the high quality and reliability that Lunar Linux is known for, while also embracing a more modern approach to distribution development.

Stay tuned for more updates as we progress on this exciting new journey!

The Lunar Linux Team
