Before installing Lunar Linux, ensure your system meets these requirements.

## Minimum Hardware Requirements

### Processor
- x86_64 (64-bit) processor
- Minimum: 1 GHz
- Recommended: 2 GHz or faster

### Memory (RAM)
- Minimum: 512 MB
- Recommended: 2 GB or more

### Storage
- Minimum: 8 GB free disk space
- Recommended: 20 GB or more for comfortable usage
- Additional space needed for source code compilation

### Graphics
- Any graphics card with Linux support
- For X11/Wayland: Graphics card with appropriate driver support

## Software Requirements

### Installation Media
- Bootable USB drive (recommended: 2 GB or larger)
- Or CD/DVD drive for ISO installation

### Internet Connection
- Required for downloading packages during installation
- Recommended: Broadband connection for faster downloads

## Supported Architectures

Lunar Linux currently supports:
- x86_64 (AMD64/Intel 64-bit)

## UEFI vs BIOS

Lunar Linux supports both:
- **UEFI** - Modern firmware interface
- **BIOS** - Legacy boot mode

Ensure you know which boot mode your system uses before installation.

## Next Steps

Once you've verified your system meets these requirements, proceed to the [Installation Guide](/docs/installation/installation-guide).
